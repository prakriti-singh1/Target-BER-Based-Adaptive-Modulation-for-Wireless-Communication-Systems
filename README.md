# Target-BER based adaptive modulation for wireless communication systems

This project simulates adaptive modulation for wireless links using BPSK, QPSK, and 16-QAM over AWGN and Rayleigh channels.

## Results

The image outputs are stored in the `Results/` folder.

- BER vs SNR — AWGN: `Results/BER_vs_SNR_AWGN.svg`
- BER vs SNR — Rayleigh: `Results/BER_vs_SNR_Rayleigh.svg`
- Switching SNR sensitivity — AWGN: `Results/Switching_SNR_Sensitivity_AWGN.svg`
- Switching SNR sensitivity — Rayleigh: `Results/Switching_SNR_Sensitivity_Rayleigh.svg`
- Throughput comparison — AWGN: `Results/Throughput_Fixed_vs_Adaptive_AWGN.svg`
- Throughput comparison — Rayleigh: `Results/Throughput_Fixed_vs_Adaptive_Rayleigh.svg`
